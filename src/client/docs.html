1. Overview & Philosophy

OmniVerse (Agent Orchestra) is an autonomous multi-agent engineering platform designed to turn simple human intent into verified, auditable, production-ready software. Instead of relying on a single monolithic prompt, OmniVerse distributes responsibilities across specialized AI roles — coordinating design systems, frontend hierarchy, application logic, AST code parsing, and deterministic QA validation in parallel.

Core Tenet: Zero Broken Commits. Code produced by agent specialists is compiled through an Acorn Abstract Syntax Tree (AST) validator and verified against automated QA safety gates before ever touching the project sandbox or live preview.

2. Quickstart Installation

OmniVerse runs on Node.js 18+ and can operate entirely offline or connected to live model providers (NVIDIA NIM, Google Gemini, Mistral, OpenRouter).

1. Clone and Install Dependencies

BASH
# Clone repository
git clone https://github.com/BIKRAM-GORAI/orchestra.git
cd orchestra

# Install dependencies
npm install

2. Configure Environment (.env)

Copy the example environment configuration and supply your API keys (optional if running in mock/offline test mode):

ENV
cp .env.example .env

# Configure one or more providers:
NVIDIA_API_KEY=nvapi-your-key-here
GEMINI_API_KEY=AIzaSy-your-key-here
MISTRAL_API_KEY=your-mistral-key-here
OPENROUTER_API_KEY=sk-or-your-key-here

PORT=3000
NODE_ENV=development

3. Launch Local Server & Verify Tests

BASH
# Run the unit and integration test suite (55 automated checks)
npm test

# Start the dev server with file watcher
npm run dev

# Open browser:
# Landing Page:   http://localhost:3000
# Simple Mode:    http://localhost:3000/simple.html
# 2.5D Studio:    http://localhost:3000/index.html

4. The 16-Agent Roster & Roles

OmniVerse organizes agents by specialized skill sets and cost tiers. Every agent has an immutable system prompt, defined input/output schemas, and deterministic state transitions:

Agent Role Category Tier Primary Responsibility
Atlas Manager / Coordinator Executive Analyzes user prompt, performs quorum alignment, decomposes task, synthesizes specialist specs.
Byte Lead Coder Free ($0.00) Writes HTML/CSS/JS using Codestral Free; fast, zero-cost generation.
Cipher Lead Coder Balanced ($0.25) Intermediate complex coding using balanced high-speed models.
Matrix Lead Coder Premium ($0.60) Advanced full-stack implementation powered by Kimi K3 & Gemini 3.5.
Pixel / Palette / Prisma Design Specialists Multi-Tier Establishes color palettes, typography tokens, glassmorphism, responsive grid geometry.
Nova / Orbit / Stella Frontend Specialists Multi-Tier Constructs clean HTML semantic structure, accessible navigation, responsive layouts.
Spark / Flux / Apex Feature Specialists Multi-Tier Implements JavaScript interaction logic, state management, client APIs, animations.
Sentinel / Query / Aegis QA & AST Auditors Multi-Tier Parses AST syntax, checks link integrity, verifies mobile responsiveness and CSP safety.
Scribe Document Analyst Multimodal Parses PDF and DOCX attachments, generates comprehensive source-grounded Markdown briefs.

5. Multi-Model Gateway & Dynamic Fallback

The ModelGateway acts as a unified abstraction layer over heterogeneous LLM providers, ensuring high availability even during upstream rate limits or outages:

FALLBACK CHAIN LOGIC
Primary Model (e.g. Kimi K3 via NVIDIA NIM)
       │
       ▼ (If 429 Rate Limit / Transient 500)
Exponential Backoff Retry (Up to 2 Attempts)
       │
       ▼ (If Outage Persists)
Secondary Model (e.g. Qwen 2.5 72B via OpenRouter)
       │
       ▼ (If Degraded)
Local Deterministic Fallback Template (Always Returns Verified Code)
Stream Accumulation: Server-Sent Events (SSE) stream agent tokens to the frontend in real time while maintaining complete buffer copies on the backend for AST validation.

6. REST & Streaming SSE API Reference

All core orchestration operations are accessible via HTTP endpoints:

POST /api/orchestrate

Trigger autonomous multi-agent code generation.

REQUEST PAYLOAD (JSON)
{
  "prompt": "Create a high-contrast dark cyberpunk portfolio with project modal previews",
  "budgetTier": "balanced",   // "free" | "balanced" | "premium"
  "stream": true
}

GET /api/projects/:id

Inspect project metadata, agent logs, file revisions, and audit scores.

GET /p/:id

Isolated sandbox live iframe preview of the generated project with strict CSP containment.

For complete JSON schemas, headers, error response payloads, and code examples, consult the root repository API_REFERENCE.md.
